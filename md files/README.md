# Vasudevan - Personal Portfolio Website

A modern, high-performance, and responsive personal portfolio website built with **React 19**, **Vite**, **Tailwind CSS v4**, **Motion**, and **Lucide React**.

---

## 🚀 Tech Stack

- **Framework**: [React 19](https://react.dev/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [Motion](https://motion.dev/) (Framer Motion)
- **Icons**: [Lucide React](https://lucide.dev/) & [React Icons](https://react-icons.github.io/react-icons/)
- **Deployment**: GitHub Pages (`gh-pages`) / Vercel

---

## 📁 Project Structure

```
vasudevan-portfolio/
├── public/              # Static assets & resume PDF
├── src/
│   ├── components/      # React section components (Hero, Navbar, About, Projects, etc.)
│   ├── data.js          # Centralized project, skill, and background data
│   ├── App.jsx          # App layout wrapper
│   └── main.jsx         # App entry point
├── md files/            # Complete project documentation & specifications
│   ├── ARCHITECTURE.md  # System Architecture & Tech Stack
│   ├── DESIGN.md        # UI/UX & Design Guidelines
│   ├── MEMORY.md        # Project Context & Memory
│   ├── PHASES.md        # Development Roadmap & Task Status
│   ├── PRD.md           # Product Requirement Document
│   └── RULES.md         # Development Rules & Coding Standards
├── index.html           # HTML template
├── package.json         # Project dependencies & build scripts
└── vite.config.js       # Vite configuration
```

---

## 🛠️ Local Setup & Development

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Start Development Server**:
   ```bash
   npm run dev
   ```

3. **Build for Production**:
   ```bash
   npm run build
   ```

4. **Preview Production Build**:
   ```bash
   npm run preview
   ```
